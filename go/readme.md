# Go in Plan 9

In this directory:
- golang.md, notes on installing/using Go (markdown ver)
- golang.ms, installing Go (troff ver)
- roff.rc, build troff.ms for lazy people

I keep this in two formats because while GitHub and any Linux system can both show
Markdown without hassle, 9front doesn't ship with a Markdown command that I'm aware of.
Now I did throw up a crappy one in Go, but you, dear reader, deserve better than that.
